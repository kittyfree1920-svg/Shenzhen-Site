# 深圳景点介绍单页网站（第一章）

一个介绍深圳各景点的单页网页应用，用于 AI 编程课第一章练习。

## 用途

- 用一页网页介绍深圳的主要景点（含内联 SVG 矢量插图）。
- 全部内容（SVG 插图、CSS、JavaScript）都内联在单个 `index.html` 里，**零外部依赖、可离线打开**。
- 本仓库是课程第一章的练习成果，通过 Git 本地存档并推送到 GitHub。

## 文件结构

- `index.html` —— 网站唯一入口，包含全部页面内容、插图与交互逻辑。
- `.gitignore` —— 忽略规则（仅忽略 `.vercel` 部署缓存）。

## 本地预览方法

### 方式一：本地服务器（推荐）

在仓库根目录打开终端，启动一个本地静态服务器：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后在浏览器打开：

```
http://127.0.0.1:8000/
```

### 方式二：直接打开

直接用浏览器打开 `index.html` 文件即可（双击或拖入浏览器窗口）。

## 部署

代码已通过 SSH 推送到 GitHub（`kittyfree1920-svg/Shenzhen-Site`，分支 `master`）。
如需公网访问，可在仓库 Settings → Pages 中选择 `master` 分支发布。
